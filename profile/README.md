### 🧵 The problem: comprehension debt
 
AI coding agents write code faster than we can understand it. In one session an agent can introduce JWT refresh rotation, a new ORM migration pattern or React Suspense — and you ship it without really knowing how it works.
 
That gap between **concepts your AI used** and **concepts you actually understand** is *comprehension debt*. It shows up later: in incidents nobody can debug, in weaker code reviews, and in developers who stop growing.
 
### 💡 How MindStitch works
 
```
1. Code as usual      → your AI agent edits files in your project
2. MindStitch notices → it spots concepts that are new to you
3. You learn in place → a short card explains what it is and why it's in *your* code
```
 
- **In your terminal** — a Claude Code plugin shows a compact card after the agent's turn, no context switch needed
- **On the web** — every card is saved, so you can track what you've learned and mark concepts as *known*
- **For teams** — engineering leads see where the team's knowledge gaps are, without reading anyone's code line by line
